## GitHub Pages

发布源使用 `main` 分支的根目录 `/`：在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/(root)**，保存。

根目录的 `.nojekyll` 让 Pages 直接发布静态文件。此后推送到 `main` 会自动更新站点。
